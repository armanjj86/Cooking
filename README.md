# قاشق‌چوبی — دفتر آشپزی من

برای ادامه‌دادن کار در سشن‌های بعدی، ساختار پروژه و روش افزودن دستور را در [HANDOFF.md](HANDOFF.md) ببین.

یک دفترچه‌ی دستور پخت فارسی، راست‌چین و کاملاً استاتیک؛ بدون بک‌اند، دیتابیس یا سرور. سایت را می‌توان با **GitHub Pages** منتشر کرد. تم روشن و تیره دارد و انتخاب تم را در همان مرورگر به خاطر می‌سپارد.

## اجرای محلی

از ریشه‌ی مخزن اجرا کن:

```bash
python3 -m http.server 8000 --directory site
```

بعد در مرورگر `http://localhost:8000` را باز کن. خود سایت در پوشه‌ی `site/` است و برای اجرا به نصب پکیج یا مرحله‌ی build نیاز ندارد.

## انتشار با GitHub Pages

۱. ابتدا تغییرها را به شاخه‌ی `main` ادغام کن؛ workflow فقط پس از push به `main` اجرا می‌شود.
۲. در مخزن GitHub به **Settings → Pages → Build and deployment** برو و **Source** را روی **GitHub Actions** بگذار.
۳. مطمئن شو GitHub Actions در مخزن فعال است. workflow موجود در `.github/workflows/deploy-pages.yml` با هر push به `main` سایت را منتشر می‌کند؛ وضعیت اجرا را از زبانه‌ی **Actions** ببین.
۴. برای اجرای دستی، در **Actions**، workflow با نام **Publish static cooking notebook** را باز کن و **Run workflow** را بزن.
۵. پس از اجرای موفق، آدرس پروژه معمولاً `https://armanjj86.github.io/Cooking/` است و از بخش **Settings → Pages** هم نمایش داده می‌شود.

## نگه‌داری دستورهای شخصی

- شش دستور داخل سایت فقط نمونه‌ی شروع هستند؛ از **افزودن دستور** برای واردکردن دستورهای خودت استفاده کن.
- دستورهای اضافه‌شده و پسندیده‌ها در `localStorage` مرورگر ذخیره می‌شوند؛ بنابراین فقط در همان مرورگر و همان دستگاه دیده می‌شوند و به GitHub یا دستگاه دیگری فرستاده نمی‌شوند.
- تم تیره/روشن در ابتدا با تنظیم سیستم‌عامل هماهنگ می‌شود؛ اگر دستی عوضش کنی، انتخابت در همان مرورگر ذخیره می‌شود.
- برای جابه‌جایی یا نگه‌داری نسخه‌ی پشتیبان، از دکمه‌ی **پشتیبان** فایل JSON بگیر و در دستگاه دیگر با **بازیابی از پشتیبان** آن را وارد کن.
- اگر می‌خواهی یک دستور برای همه‌ی بازدیدکننده‌ها نمایش داده شود، آن را به فهرست `sampleRecipes` در `site/app.js` اضافه کن. هر چیزی که در کد یا مخزن عمومی قرار بگیرد برای بازدیدکنندگان قابل مشاهده است.
